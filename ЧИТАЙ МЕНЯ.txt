StudioDrop — передача файлов между ПК, Mac и телефонами в одной Wi-Fi сети.

Готовые файлы (StudioDrop.exe и .dmg) собираются автоматически на GitHub: вкладка Releases.
Каждая сборка сначала проходит автотесты на реальных Windows и Mac (tests/smoke.py).

ПЕРВЫЙ ЗАПУСК
Windows: SmartScreen может написать "Неизвестный издатель" -> Подробнее -> Выполнить в любом случае.
Mac: приложение не подписано Apple. Первый раз: правая кнопка по StudioDrop -> Открыть -> Открыть.
Оба: при запросе брандмауэра/локальной сети нажмите "Разрешить".
